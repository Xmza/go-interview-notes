## Что такое слайс?
Слайс — это обёртка над массивом с длиной и ёмкостью. Передаётся по значению, но как ссылка на массив.
<pre>Слайс не владеет данными, а указывает на часть массива.
Изменения элементов слайса изменяют и массив.
Структура: указатель на массив, длина (len), ёмкость (cap).</pre>

## Чем массив отличается от слайса? Чем хорош массив по сравнению со слайсом?
Массив — это фиксированной длины структура, слайс — динамический, может менять длину и указывает на массив.

<pre>
Массив передаётся по значению и копируется целиком.
Слайс легче по памяти, гибче и удобнее для большинства задач.
Массив лучше, если нужна точная длина и контроль, например, в криптографии ([32]byte).</pre>

## Как работает append?
append добавляет элементы в слайс. Если места хватает — просто добавляет. Если нет — создаётся новый массив большего размера, данные копируются, и возвращается новый слайс.

## Какие методы оптимизации работы со слайсами ты бы применил в работе?
Как вариант предварительное выдаление ёмкости через `make` с указанием capacity, чтобы избежать частых копирований.  
<pre> - Использовать make([]T, 0, N), чтобы избежать лишних аллокаций при росте. 
  - Избегать срезов с большим cap, если нужно освободить память (например, делать копию). 
  - Использовать copy при разделении слайсов, чтобы избежать скрытых связей. </pre>

## Какая есть функции для создания слайса с длиной отличной от нуля?
make([]T, length, capacity) — создаёт слайс с нужной длиной и ёмкостью.

<pre> - Например: make([]int, 5, 10) создаст слайс длиной 5, в который можно добавить до 10 элементов без пересоздания. 
  - По умолчанию значение элементов — нулевое (0 для int, "" для string и т.д.). </pre>

## С какой скоростью идет поиск в массиве и почему?
Поиск в массиве линейный — O(n), так как массив — просто последовательность элементов без индексации.
