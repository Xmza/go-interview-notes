## Что такое интерфейс?
Интерфейс — это набор методов. Любой тип, реализующий эти методы, автоматически соответствует интерфейсу.

<pre> Интерфейс в Go — это "контракт", а не класс. Он описывает поведение, а не структуру. </pre>

## Для чего используются интерфейсы и как они устроены?
Интерфейсы позволяют писать универсальный код — обрабатывать разные типы по общему поведению. Под капотом интерфейс содержит указатель на значение и указатель на тип.

<pre> Это нужно для полиморфизма: можно принимать интерфейс, но работать с разными типами. </pre>


### Зачем нужен пустой интерфейс?
Пустой интерфейс (interface{}) принимает любой тип, потому что не требует реализации методов.

<pre> Используется в местах, где нужно хранить значения любых типов, например: fmt.Println, map[string]interface{} и т.д. </pre>

### Чем пустой интерфейс отличается от пустой структуры?
interface{} — это универсальный контейнер для любого значения, используется, когда нужно принимать/передавать "что угодно".
struct{} — это структура без полей, занимает 0 байт, часто используется как флаг для заглушек или оптимизаций.

<pre> interface{} — это "любой тип", struct{} — это "ничего", но типизировано. </pre>

### Есть интерфейс, а есть указатель на структуру, который nil. Кладем указатель в интерфейс. Что если сравнить интерфейс с nil?
Результат — false. Интерфейс не nil, потому что внутри есть тип (*Struct) + nil-значение.

<pre> Интерфейс считается nil, только если в нём нет типа и значения одновременно. Так что даже nil-указатель внутри интерфейса ≠ nil-интерфейс. </pre>
