## Что такое defer, порядок выполнения, оптимизации компилятора

`defer` откладывает вызов функции до выхода из текущей функции.
Порядок выполнения: **LIFO** (последний добавленный выполняется первым).

Оптимизации: компилятор умеет встраивать `defer` для функций без циклов → быстрее.

Пример:

```go
func f() {
    defer fmt.Println("first")
    defer fmt.Println("second")
}
// Вывод: second \n first
```

## Как работает init(), порядок вызова в пакете и между пакетами

В Go init() используется для инициализации. (Инициализация — это приведение переменной или объекта в начальное, корректное состояние, чтобы с ним можно было работать.)   
- В пакете она выполняется после глобальных переменных, 
- между пакетами — сначала у зависимостей, потом у текущего.
- В main она вызывается перед самой функцией main().

* В каждом пакете можно объявить функцию `init()`.
* Вызывается автоматически при импорте пакета, до `main()`.
* В пакете может быть несколько `init()` → выполняются по порядку объявления.
* Между пакетами: порядок инициализации соответствует графу зависимостей (сначала зависимости, потом импортирующие).

## Чем отличается new и make

* `new(T)` → выделяет память под тип, обнуляет его (zero value) и возвращает указатель.
* `make(T, ...)` → используется только для `slice`, `map`, `chan`, создаёт и инициализирует внутренние структуры.

<pre>
new работает с любыми типами и возвращает указатель на zero value, а make используется только для трёх встроенных коллекций и возвращает не указатель, а сам объект.
</pre>

## Что произойдет если сравнивать слайсы

В Go напрямую слайсы сравнить нельзя, кроме как с nil.  
Если попробуешь s1 == s2, то будет ошибка компиляции. Чтобы сравнить содержимое, обычно пишут цикл или используют reflect.DeepEqual,  
а начиная с Go 1.21 можно юзать slices.Equal. Это сделано специально, потому что слайс — это ссылка на массив, и простое сравнение было бы неоднозначным.

## Что такое alias типов (type A = B) vs новый тип (type A B)

Alias — это просто синоним существующего типа (например, byte = uint8). 
Новый тип — это отдельный тип на базе существующего, с которым нельзя путать оригинал, и можно добавлять методы.

## Как работает copy для слайсов

Функция copy(dst, src) копирует элементы из одного слайса в другой и возвращает число реально скопированных элементов.  
Правило простое: скопируется ровно столько элементов, сколько влезет в меньший из двух слайсов.

```go
src := []int{1, 2, 3}
dst := make([]int, 2)

n := copy(dst, src)
fmt.Println(dst, n) // [1 2] 2
```
> Здесь скопировалось 2 элемента, потому что длина dst — 2.

## Что такое rune и byte в Go

* `byte` = `uint8`, используется для байтов (ASCII, сырой ввод/вывод).
* `rune` = `int32`, используется для Unicode-кода символа.

---

## Что будет если вернуть из функции ссылку на локальную переменную

byte = uint8. То есть просто число от 0 до 255. Обычно используют, когда работаешь с «сырыми байтами» — файлы, сеть, []byte для строк.

rune = int32. Это число, которое хранит Unicode-код символа. Нужно, чтобы нормально работать с буквами не только латиницы, но и любых языков.
