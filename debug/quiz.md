## 1. Параллелизм vs Конкурентность
Какое утверждение верно описывает разницу между ними в Go?

- [ ] A) Это одно и то же.
- [ ] B) Конкурентность — это одновременное выполнение на разных ядрах, а Параллелизм — это структура программы.
- [ ] C) Конкурентность (Concurrency) — это про структуру программы (dealing with lots of things at once), а Параллелизм (Parallelism) — про выполнение (doing lots of things at once).
- [ ] D) Go поддерживает только конкурентность, но не параллелизм.

<details>
<summary>✅ Правильный ответ</summary>

**Ответ: C**

Как говорил Роб Пайк: "Concurrency is not parallelism". 

Конкурентность позволяет нам писать код так, будто он выполняется одновременно (через горутины), а будет ли он выполняться физически параллельно (на разных ядрах) — решает планировщик и железо.

</details>

## 2. Default Values (Нулевые значения)
Чему равно "нулевое значение" (zero value) для типа `bool` и указателя `*int`?

- [ ] A) `true` и `0`
- [ ] B) `false` и `0`
- [ ] C) `false` и `nil`
- [ ] D) `true` и `nil`

<details>
<summary>✅ Правильный ответ</summary>

**Ответ: C**

Для `bool` дефолтное значение — `false`.

Для всех указателей (pointers), интерфейсов, мап, слайсов и каналов — `nil`.

Для чисел — `0`.

Для строк — `""` (пустая строка).

</details>

## 3. Массивы и Слайсы
Что произойдет, если передать **массив** (не слайс) в функцию и изменить его там?

```go
func change(arr [3]int) { arr[0] = 999 }
```

- [ ] A) Исходный массив изменится (передача по ссылке).
- [ ] B) Исходный массив НЕ изменится (передача по значению).
- [ ] C) Возникнет ошибка компиляции.


<details>
<summary>✅ Правильный ответ</summary>

  Ответ: B

В Go массивы — это значения (value types). При передаче массива в функцию он полностью копируется. Изменения внутри функции затрагивают только копию.

Чтобы изменить исходный массив, нужно передавать указатель *[3]int или использовать слайс []int.
</details>

## 4. Каналы (Channels)
Что будет, если попытаться записать данные в nil канал (неинициализированный)?

```Go
var ch chan int
ch <- 1
```
- [ ] A) Паника (panic).
- [ ] B) Данные пропадут.
- [ ] C) Вечная блокировка (deadlock).
- [ ] D) Ошибка компиляции.

<details>
<summary>✅ Правильный ответ</summary>

  Ответ: C (Deadlock)

Запись в nil канал и чтение из nil канала блокируют горутину навсегда. Если это происходит в main goroutine и нет других работающих горутин, рантайм выбросит ошибку fatal error: all goroutines are asleep - deadlock!.
</details>

## 5. Map Keys
Какой тип данных НЕЛЬЗЯ использовать в качестве ключа в map?

- [ ] A) string
- [ ] B) int
- [ ] C) struct (если поля сравнимы)
- [ ] D) []int (слайс)
<details>
<summary>✅ Правильный ответ</summary>

  Ответ: D (Слайс)

Ключи в мапе должны быть comparable (сравнимыми), то есть поддерживать операцию ==.

Слайсы, мапы и функции в Go не сравнимы (их нельзя сравнить через ==), поэтому они не могут быть ключами.

Структруры могут быть ключами, если все их поля сравнимы.
</details>

## 6. Goroutine Size
Каков примерный размер стека горутины при создании?

- [ ] A) 1 MB (как поток в Java)
- [ ] B) 2 KB
- [ ] C) 64 KB
- [ ] D) 4 KB
<details>
<summary>✅ Правильный ответ</summary>

  Ответ: B (2 KB)

Горутины очень легкие. Они начинают с крошечного стека (обычно 2 KB), который может динамически расти и уменьшаться при необходимости. Потоки ОС обычно занимают 1-2 MB.
</details>

## 7. Visibility (Область видимости)
Как сделать функцию или переменную доступной из другого пакета (экспортируемой)?

- [ ] A) Использовать ключевое слово public.
- [ ] B) Использовать ключевое слово export.
- [ ] C) Назвать её с Большой Буквы.
- [ ] D) Объявить её в файле export.go.
<details>
<summary>✅ Правильный ответ</summary>

  Ответ: C

В Go область видимости определяется регистром первой буквы.

func MyFunc() — Public (экспортируемая).

func myFunc() — Private (доступна только внутри пакета).
</details>

## 8. Select Statement
Что произойдет в конструкции select, если готовы к выполнению сразу несколько case (например, в два канала одновременно пришли данные)?

- [ ] A) Выполнится первый по порядку (сверху вниз).
- [ ] B) Выполнится случайный (random) case.
- [ ] C) Программа запаникует.
- [ ] D) Выполнятся оба параллельно.
<details>
<summary>✅ Правильный ответ</summary>
Ответ: B
select специально выбирает псевдослучайный готовый case, чтобы избежать голодания (starvation) какой-то одной ветки кода, если данные идут потоком везде.
</details>
